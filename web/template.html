The costs to remember

n = stored elements; k = inspected elements. Bounds assume constant-time element comparison/copy unless stated otherwise; hashing costs depend on the key.
OperationTimeThe catch
Array append / popLastO(1) amortized / O(1)Shared storage can copy O(n) on mutation.
Array removeFirstO(n)Shifts elements. Use a head cursor for BFS.
Dictionary / Set lookupO(1) expectedO(n) worst case; hashing is not free.
Binary heap push / popO(log n)O(1) peek; heapify O(n). Excludes a shared-buffer copy.
String offset indexO(k)Characters have variable width; not integer subscripts.
