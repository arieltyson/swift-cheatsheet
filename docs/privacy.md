# Privacy

The website has no accounts, cookies, analytics, search telemetry, remote fonts, embedded media, or application storage. It does not read the clipboard. Copy buttons write only the selected example after an explicit click; denied clipboard access leaves manual text selection available.

Browser find is handled by the browser. Appearance follows the system through CSS; no theme preference is saved. No query or copied code is sent by application JavaScript.

[GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) processes visitor IP addresses for security. External documentation links contact their destination when followed. These hosting/browser behaviors are distinct from application-level tracking.

The public artifact contains `index.html`, `styles.css`, `app.js`, `favicon.svg`, and `.nojekyll`. It excludes source planning documents, credentials, test fixtures, screenshots, and build caches. The repository intentionally contains public source and tests; do not add private interview notes or documents to it.

[Report a problem](https://github.com/arieltyson/swift-cheatsheet/issues). Do not put sensitive information in public issues.
